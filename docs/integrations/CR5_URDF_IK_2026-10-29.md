# CR5 本体模型、本地 Pinocchio IK 与 VR 整链记录

日期：2026-10-29。需求：只迁移用户指定描述仓库的 CR5 本体，排除夹爪、ros2_control、OCS2，使用 URDF / Pinocchio 数值求解完成右手柄与右手追踪遥操。

## 当前实现

纯 CR5 模型已进入统一 `src/robot_description`：

- `urdf/cr5/cr5.urdf`：固定基座、7 link、6 个 revolute joint，无末端夹爪或外部控制插件。
- `meshes/cr5`：7 个视觉 OBJ、对应 MTL 与 12 个碰撞 STL，保留源文件。
- `config/asset_manifests/cr5.yaml`：独立补充模型清单，ID `cr5_arm`，包含目标 URDF 和网格/材质哈希。
- `docs/cr5`：MIT 许可、来源/迁移说明及源文件 SHA-256。

URDF 来源是 arm.xacro 的空前缀 CR5 宏、convex 碰撞分支和 tf_params.yaml。源轴、惯量、原点数值精度及限位保持；mesh URI 改为统一包地址。没有迁入上游夹爪、场景、ros2_control、OCS2、旧 launch 或这些模块的配置。

为保持原 Nero/Astral 冻结 profile 的资源 revision 不变，原 asset_manifest.yaml 逐字保留；公共资源查询与资产检查增加读取 `config/asset_manifests/*.yaml`。CR5 继续随现有 robot_description CMake 安装，没有嵌套 ROS 包。

独立求解器位于 `src/robots/dobot/morla_cr5_driver/morla_cr5_driver/urdf_ik.py`，具备与公共 CartesianController 一致的 `sync_state / fk / solve` 接口。采用 Pinocchio 固定基座模型、SE(3) 对数误差、Jacobian、阻尼最小二乘及线搜索，增加以下检查：

- canonical joint1..joint6 顺序与六自由度结构检查、URDF SHA-256 绑定。
- 从实测硬件关节播种，明确 `q_model = signs*q_hardware + offsets`；FK/Jacobian/IK 一致映射。
- URDF 与部署限位交集；第 3 关节保留模型的 ±2.7925 rad。
- 围绕种子最大 ±0.3 rad 的局部求解域，不随机重启或切到远解；每次迭代增量 ≤0.06 rad。
- 最大 100 次迭代、50 ms 求解预算；成功前用返回关节重新 FK，位置误差 ≤0.2 mm、旋转误差 ≤0.002 rad。
- 不可达、停滞、限位或超时返回失败；不回退控制器 IK。

fake 和 real 的 VR factory 都选择这个本地求解器；fake 仅反馈与设备行为由 FakeAdapter 合成，不再用合成几何作为默认遥操求解。旧 ControllerSolver/FakeSolver 保留为早期协议回归辅助，不被 VR factory 选择，真实 Adapter 不再提供控制器 IK provider。

完整链为右侧 Quest 事件 → 来源/时效/deadman → 公共相对位姿/TCP → CR5 本地 IK → 异步结果隔离/限速 → runtime 授权/TTL → 独立驱动 ServoJ。外层关节步长默认 0.15 rad、输出速度 0.3 rad/s；右握把和裸手捏合均支持移动、释放与切换撤权。默认 disarmed，不自动激活。

详细现场流程见 [CR5 VR 操作说明](cr5_vr.md)。只读 probe 默认仅读取硬件关节，再执行本地 FK/IK；不会发送控制器 IK 或运动命令。可选 controller FK 比较仅用于坐标诊断，不代替物理标定。

## 实际验证与证据

测试环境：macOS、Python 3.13 独立测试环境 `/tmp/morla-cr5-vr-tests`、Pinocchio 4.1.0；没有 ROS/实体设备。

- **144 项纯软件测试通过**：[pure.txt](evidence/2026-10-29-cr5-urdf/pure.txt)。新增实际 URDF 与独立 XML 变换积 FK 对照、100 组邻近位姿求解、60 帧连续轨迹、正负号/偏置及部署交集限位、不可达/奇异保持/超时/模型哈希、安装后资源解析，以及真实 factory/probe 不调用控制器 IK。整链测试使用真实 CR5 几何，覆盖右手柄运动、裸手切换后运动、释放建锚和捏合断流撤权。
- **23 项 fake 集成回归通过**：[fake.txt](evidence/2026-10-29-cr5-urdf/fake.txt)。现有数据/策略/Web 行为通过。
- **源模型等价检查通过**：[source_equivalence.txt](evidence/2026-10-29-cr5-urdf/source_equivalence.txt)。六关节 origin/axis/父子/限位、7 link 惯量数据逐项与源宏及 TF 对照，26 个网格/材质逐字节相同。
- **模型与网格加载通过**：[model_assets.txt](evidence/2026-10-29-cr5-urdf/model_assets.txt)。CR5 目标/网格/材质哈希闭包通过，实际 Pinocchio RobotWrapper 加载 6 DOF、7 个 visual、12 个 collider。
- **最终 wheel 与安装布局验证通过**：[installed.txt](evidence/2026-10-29-cr5-urdf/installed.txt)。独立构建输入/CR5 wheel，真实加载 entry point；从临时 share 解析并加载 CR5 URDF，验证安装后的控制页 HTTP、手柄运动、释放撤权与线程/锁清理。输入和驱动从 wheel 加载，公共框架从源码加载；robot_description 资源按普通 share 布局复制，ament 查询用受控替代，未声称 colcon 构建。脚本：[verify_installed.py](evidence/2026-10-29-cr5-urdf/verify_installed.py)。
