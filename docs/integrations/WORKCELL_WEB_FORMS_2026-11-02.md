# 工作站配置表单与交互调整

日期：2026-11-02。在现有公共仿真、CR5 微分 IK 的未提交工作之上修改 Web，保留此前功能。本轮只改变前端配置生成和呈现，复用已有 /api/v2 校验、版本保存、设备运行与采集接口，不新增硬件控制通道。

## 页面顺序

原「组合配置」调整为「工作站」，以页签组织：设备选型 → 安装与标定 → 遥操作设置 → 数据记录 → 检查与运行。没有数字步骤标题；每页底部提供下一项入口，也允许直接返回已配置的内容。

顶部统一管理当前配置、已有工作站和仿真预设。运行中配置只读，停止后才能修改；运行选项、运动使能和数据记录位于末页。运行中的工作站在页面重新打开后自动恢复到运行页。旧 Profile 操作入口保留在「独立控制」，去掉原数字段落标题。

## 表单生成内容

- 设备：输入、机械臂/末端、相机按用途分区；运行方式、显示名称与常用参数直接选择。其余参数从安装的组件 descriptor.configuration_schema/defaults 生成类型化字段，支持数值、文本、枚举、布尔、向量和嵌套属性。已有未识别参数保留。
- 安装：选择安装对象和父坐标系，通过 XYZ（m）与 Roll/Pitch/Yaw（°）编辑位姿，页面转换成规范化 xyzw 四元数；工具 TCP 同样用位姿表单转换为 4×4 矩阵。仅显式编辑时重新编码已有变换，未编辑的值不因显示而改写。
- 输入方向：选择各输入正轴对应的机器人轴，也可使用数值矩阵编辑任意已标定方向。只显示已有标定而不自动标记现场核验完成；不合法的方向组合由公共配置校验拒绝。
- 连接：真实设备的标识、资源键、IP、串口、总线等在表单填写。设备身份核对和停止测试保持人工勾选，切到 real 不自动核验，也不自动连接。
- 遥操作：输入信号、控制目标、控制方式、运动使能信号、输入有效期、位移倍率、速度、滤波、关节/笛卡尔轴分配、IK 模式和微分参数均为表单。TCP 和坐标变换紧随控制映射设置。
- 控制组：添加联动停止组并勾选执行器。未分组执行器沿用公共运行时的独立组；后台仍检查重复归组等冲突。
- 数据：观测、动作和辅助信号勾选，图像数据名、记录频率和动作来源设置。普通操作无需编辑投影 JSON。
- 文件：JSON 仅保留在底部「配置文件 · 导入与导出」的可选文件工具和开发者编辑区。导入在替换前检查结构并要求确认；导出同时保存 assembly/deployment，保留未知字段，不要求用户重写一份配置。

前端没有推导实际标定、硬件地址或安全验收信息。新建几何默认是明确的世界坐标安装，用户可修改；相机初始视角复用已有可信仿真模板。Nero/Astral 新建位姿控制优先复用既有模板按侧别生成的标定；变更后仍需核对实际方向。

## 修正的配置行为

旧「添加绑定」将同一组 axes_map 数组和 speed 参数带到不同控制器；切换到 CR5 Cartesian 后会留下不适用参数。本轮按输入能力和目标类型选择控制器，并按实际控制器约定生成默认值：

- 关节点动：每关节一个轴的数组，未提供的输入轴留空。
- 末端速度控制：x/y/z/roll/pitch/yaw 命名轴字典、平移/转动速度；CR5 选择自己的 Cartesian 插件。
- Quest 位姿：符合 raw Unity 左手约定的输入变换和工具变换；公共 Nero/Astral 优先使用已有 Profile 推导的预设。
- 线性、捏合和滤波扳机：分别生成它们实际读取的范围/滤波参数，不提供无效的统一 input_range。

切换输入、目标或控制方式会重新生成该映射参数，页面明确提示重新核对。新建摇杆映射默认选择同源 hold_to_control 使能信号（若存在）；位姿连续跟随仍允许不使用按住信号。切换仿真/测试/真实方式时同步清除旧 deployment.backend 覆盖，避免选项显示与保存后端不同。

新草稿显式记录 kinematic/web；载入原本未设置 simulation 的配置时保留其缺省状态，与运行时 physics/web 默认一致。界面不会把未设置的枚举误显示为已选第一个值。

## 视觉与术语

使用石墨灰背景、细边框和单一低饱和强调色；移除配置页渐变、发光装饰、表情符号和按类别彩色卡片。设备用统一表单行呈现，信息层级由排版和间距区分。桌面宽度固定一致，窄屏字段自动换列。

普通流程使用「控制映射」「安装位姿」「父坐标系」「工具中心点 TCP」「运动使能」「数据记录」「检查与运行」等术语；内部 plugin/port ID 仅作设备标识或在诊断中保留。「冻结数据契约」改为检查摘要。独立公共控制台的工作站页不再将缺少旧 ROS /api/v1 遥测显示为整站故障。
