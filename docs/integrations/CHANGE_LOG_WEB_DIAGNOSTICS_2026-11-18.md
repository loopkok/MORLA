# 2026-11-18 Web 遥操诊断日志变更

- Web 新会话默认记录启停、控制权切换、故障和设备健康变化，跳过逐帧输入、控制快照、IK 报告和成功指令回执。
- 在「会话与诊断 → 日志文件配置」可选择每秒采样、逐帧排障或关闭诊断日志。每秒采样在构建快照和收集 IK 报告之前限频，设备健康变化与故障仍即时记录。保存装配后下次启动生效。HDF5 数据采集独立运行。
- 输入按来源、控制按绑定、反馈按设备至多每秒采样一次。短于一秒的波动可能漏采，需要对齐每一帧输入、控制和指令时可短时切换到逐帧模式。

## 验证

- 诊断日志、绑定引擎、Web API 和操作者控制共 84 项回归通过，前端 48 项测试及 TypeScript/Vite 构建通过。
- MMK2 模拟 SDK 日志按虚拟 90 Hz 离线回放 10 秒。逐帧模式写入 9,900 条高频记录，按秒采样写入 100 条。日志入口平均每帧开销分别为 1.063 ms 和 0.021 ms，两者均无队列丢弃。
- 离线回放只计日志入口的快照和入队开销。MMK2 真机遥操延迟和抖动待实测。
