# XHand 1 软件目标限位依据

依据 `docs/xhand使用手册/[使用说明书]XHAND 1_带触觉单包_v1.3.pdf` 第 4 页，
第 3.2 节的角度范围及同页关节 ID 图，软件目标限位按以下原生 SDK 关节 ID 配置：

- ID 0，拇指旋转 `thumb_bend_joint`：0°～90°。
- ID 1，拇指近端弯曲 `thumb_rota_joint1`：−60°～90°。
- ID 2，拇指远端弯曲 `thumb_rota_joint2`：0°～90°。
- ID 3，食指侧摆 `index_bend_joint`：−5°～17°。
- ID 4～11，食指、中指、无名指、小指的两级弯曲：0°～110°。

手册没有分别列出左右手两套数值。本配置按同一 SDK ID 的原生角度应用于两手，
不在此处叠加遥操作重定向的镜像符号，也不修改关节轴、零点或运动学坐标系。
精确度数保存在 `morla_xhand_hand/config/xhand1_manual_limits.json`，
控制配置通过 `math.radians` 精确换算为 rad，不再沿用约三位小数的旧 URDF 数值。

同步范围包括 XHand 组件、适配器参数、Nero XHand Profile、当前 URDF 与其仿真模型、
外部钢琴项目模板和服务器已保存的钢琴配置。历史会话快照和标为 legacy 的模型保留原样。
修改活动模型的限位会改变 Profile schema hash；已冻结的数据集 schema 保留原样。

迁移只替换 `hands.*.hand_limits_rad`，不改演奏零位、工作位、悬停/按下角、移位点、
手部内部标定、Flash、控制增益、到位容差或真实反馈。先验证所有已保存目标仍在新范围内；
若不在范围内，报告冲突，不自动夹紧或重写目标。目标限位变化后需重新认证配置。
部署前断开钢琴会话，重新建立会话后才会加载新限位。

本次左手食指侧摆目标 3.625°、反馈约 1.571° 均在手册范围内；
约 2.054° 的跟踪误差仍可能超过独立的到位判据，修改限位不能据此解决到位超时。
