## 接入硬件后仍需完成

新机当前没有USB-CAN和ttyUSB设备。不能从旧电脑的USB端口号推断新电脑左右连接。

```bash
cd /home/loopkok/MORLA
bash scripts/can_muti_activate.sh --status
```

沿线确认左右机械臂，编辑 config/nero_can_ports.local.json 的 left_bus_info 和 right_bus_info。保留bitrate为1000000。两个值都必须与status输出中的实际bus_info一一对应。未填写或不匹配时，激活脚本会退出，不改变接口。此步骤只设置主机接口，不代表机械臂已复位或使能。

接好双臂、双手并完成映射后，正常启动：

```bash
cd /home/loopkok/MORLA
bash scripts/nero_web_start.sh --no-quest
```

硬件尚未接入时，若只查看Web和做纯软件演练，可绕过硬件一键脚本：

```bash
source /opt/ros/humble/setup.bash
source /home/loopkok/MORLA/install/setup.bash
ros2 launch morla_web_manager web_manager.launch.py web_host:=0.0.0.0 web_port:=8080 voice_source:=off quest_preview:=false
```

新机未安装tmux（不属于本次前四项）；通过SSH运行时需保持终端，或另行配置进程托管。
