## 已修正

1. **跨页面并发运动**：后端原子互斥和会话占用阻止遥操/策略/采集等竞争，急停独立放行。
2. **残留驱动**：除命令话题外，启动前检查状态与反馈发布者，执行中再次检查标准和原生接口。
3. **旧控制权缓存**：之前会把刚退出的钢琴租约误认成仍存在的策略节点；现重查实时 ROS 图。
4. **停止竞态**：增加取消代次检查，准备/演奏初始化不能吞掉相邻停止请求，旧排队动作不再继续。
5. **异常返回自身出错**：去除重复 error 关键字，非法操作只返回失败，不令执行进程崩溃。
6. **运行中改参数**：增加版本检查、跨进程文件锁、原子写入及会话参数快照。活动会话拒绝修改，编辑默认撤销认证。
7. **放宽硬件边界**：用户参数不能扩大 MORLA 关节硬限位；拒绝 NaN/Infinity、错误维度、其他手指关节及超出速度/超时边界的值。
8. **黑键姿态被白键复用**：独立核心为黑键专用姿态保留索引，普通白键自动指法跳过这些索引，新增核心回归测试。
9. **只确认抬起未确认按下**：跟踪按下关节实测值；超时或抬起前未确认则故障停止。过短时值预检拒绝。
10. **多个 Web 实例**：增加同域 OS 锁、跨域真机资源锁并传给子进程，避免仅依赖单 Web 内存锁。
11. **进程遗留/服务失联**：监督线程与执行进程均可清理所属驱动组，浏览器租约和父子心跳分别处理页面、服务失联。
12. **执行进程突然死亡**：增加仅急停恢复进程，不获取运动权、不使能、不发送关节目标。恢复结果保留独立状态，不会被清理日志挤掉。
13. **清理后仍显示已连接**：显式清除连接状态，异常退出及续租超时保留原因；不把进程退出当作实体停稳。
14. **路径/命令注入和大输入**：随机曲谱 ID、固定根目录、argv 启动、不经 shell 拼接；导入有大小/数量限制，同源检查保护新控制接口。
15. **非法高级 JSON 影响原页面**：应用到前端草稿前由服务器验证，防止缺字段导致整个 React 页面崩溃。

## 边界
