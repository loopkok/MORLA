# 外部设备接入实施与验证日志

2026-11-18。基线为 `e14d280`。改造目标是让第三方在独立包里交付设备描述、驱动适配、预设和模型资源，安装后用工作站配置完成接入。 [优化计划](EXTERNAL_COMPONENT_OPTIMIZATION_PLAN.md)

## 实施记录

- **安装和发现** 增加标准 wheel 静态索引与安装资源查找。目录发现只读静态数据，Adapter 由选中的实例加载。目录和预设会隔离歧义身份，安装诊断记录失败来源。
- **装配和 Web** 增加 `port_roles`，让默认反馈、命令、预览与采集按设备能力解析。显式采集配置优先。相机预览可按实例和端口选择，原默认预览入口继续可用。
- **反馈和录制** 增加 `sample_fields` 及具名字段录制，复用 HDF5 写入器保存类型、形状、单位和时间信息。Web 生产包已重建。
- **交付方式** 提供机械臂、米制夹爪、双路相机和多字段传感器的外部包样例。CI 新增 `external` 验收，构建并安装真实 wheel 后验证预设、控制和落盘。 [组件 SDK](SDK.md) · [样例](../../examples/external_components/README.md)

## 验证与兼容性

- 实施期通过 278 项公共链路回归、229 项厂商包回归、25 项共享仿真回归和 48 项 Web 单元测试。外部 wheel 验收验证了 HDF5 字段及单位。Edge 在临时 fake 工作站验证了双路画面切换和页面录制。
- 提交前复跑外部 wheel 验收与 48 项 Web 单元测试，均通过。Git 差异空白检查通过。
- 对照基线核对了 62 份装配及部署组合。59 份通过编译，快照及哈希一致。12 个旧 Profile 通过，Schema 一致。64 个组件描述及 10 个 Web 预设一致。
- 另 3 份配置在基线和当前版本均有相同拒绝原因。Quest 裸手捏合示例缺少输入坐标约定，两个 MMK2 真机装配单独编译时缺少部署设备标识。使用临时补全配置可通过编译。
- 本轮验收范围为软件、仿真和本机 SDK 协议模拟。ROS/DDS 与物理设备联调由目标环境验收。
