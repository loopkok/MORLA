# MMK2 末端位姿跟随

`morla.mmk2.cartesian_delta` 为 MMK2 左右臂提供异步控制。仿真和 SDK 共用
`mmk2_description` 的 URDF，从各自的臂基座求解到夹爪中心。Quest 绑定仍由
MORLA 管理，包括坐标映射、标定、使能键和命令生命周期。

求解沿用 FR3、CR5 的差分 IK 结构：局部 SE(3) 误差、自适应阻尼、整组限步和
正解回溯。每拍从当前原始目标重新计算领先范围，贴限位且向外的关节锁住后重解。实际输出在速度及反馈领先限制后再次检查正解，并限制旋转跟随带来的
位置偏离。任务不可达时保持上一有效关节目标。

新建 MMK2 Quest 绑定默认选择「末端位姿跟随 · MMK2」。旧工作单元可在
「链接关系图」编辑左右臂绑定，保留现有坐标映射及标定，切换控制器后保存新版本。
SDK 真机的写入门禁仍由驱动管理。
